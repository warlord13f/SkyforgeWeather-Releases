# Skyforge Weather Releases

This repository distributes signed Skyforge Weather installers and the update manifest used by the application's automatic updater.

Skyforge Weather is a live weather engine for Lockheed Martin Prepar3D v5 and v6.

## Downloads

Installers are published on the repository's **Releases** page. Only installers digitally signed by the Skyforge Weather publisher should be trusted.

## Update channel

`update.json` describes the current public release. Skyforge Weather checks this file silently and only starts an update when a newer, validly signed release is available.
